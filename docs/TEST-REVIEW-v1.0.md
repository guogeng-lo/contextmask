## 可重現問題

### R01：JSON 密碼值位於下一行時漏遮

```json
{"password":
 "SYNTHETIC_SECRET_ABC"}
```

v1.0 找不到候選，輸出不變，檢查通過且可複製。修正後應完整辨識合法 JSON 中跨行排版的敏感欄位值，遮罩資料並保持有效 JSON、精確還原。不能僅對本範例加特例或以提示代替此已確認問題的修正。

### R02：YAML 引號與多行值部分漏遮

```yaml
password: 'demo''SYNTHETIC_SECRET_SUFFIX'
```

v1.0 只遮住 `demo`，其餘資料留下，且可複製。YAML 中連續兩個單引號是同一字串內的單引號轉義。

```yaml
password: |
  SYNTHETIC_SECRET_ABC,;
  SECOND_SECRET_XYZ;
```

v1.0 替換文字但留下行尾逗號、分號；YAML 多行值中的這些符號屬於資料。支援的語法須完整遮罩值並保留外側結構；確實不支援的形式須明確列為未完整處理，依 D03 處理，不能靜默產生看似完整的結果。

參照：[YAML 單引號語法](https://yaml.org/spec/1.2.2/#732-single-quoted-style)、[YAML literal block](https://yaml.org/spec/1.2.2/#812-literal-style)。

### R03：Python 單行三引號密碼靜默略過

```python
password = """SYNTHETIC_SECRET_ABC"""
```

v1.0 無候選，也無針對此語法的提示，可直接複製。修正方向為完整支援，或對已辨識敏感欄位明確說明尚未完整處理，依 D03 要求確認。多行三引號的支援範圍需明確記錄。

### R04：有效 JSON 純值未套用輸出檢查

原文 `123456`，自訂學號文字 `123456`，輸出 `SID_1`；或原文 `true`，自訂其他文字 `true`，輸出 `WORD_1`。v1.0 顯示原文不是 JSON、略過檢查，仍可複製。

兩個原文均可被 `JSON.parse` 解析，輸出則不行。修正後檢查應包含 JSON 物件、陣列、字串、數字、布林及 null；破壞原本有效 JSON 時仍阻擋複製，不能以 D03 的風險確認越過。

### R05：瀏覽器測試缺乏可攜性

`tests/e2e.cjs` 寫死 `executablePath: '/opt/pw-browsers/chromium'`。改為預設使用 Playwright 安裝的瀏覽器，或提供明確的可選路徑設定。README 的伺服器與測試指令需分清執行目錄及不同終端，讓一般 Windows 環境可依說明重現。

### R06：CSP 與隱私文字需精確

內嵌 script/style 修改後須更新 CSP 雜湊；普通 HTML 文字修改不必然使整頁程式失效。CSS 雜湊不符與 JavaScript 雜湊不符的效果也不同。公開說明與開發文件須依實際範圍描述。網頁處理不主動上傳輸入，但 CSP 無法涵蓋所有擴充功能或外部環境的存取風險。

## 已確認的作者決策

- D01：短代號供使用者容易閱讀，預先保留原文既有代號、跳號，只精確還原本批映射，未知代號不猜測。
- D02：原文與結果保留對照，以版面小修、資訊收合及就近提示降低門檻；一般正常流程不增加強制彈窗、切頁或重複確認。
- D03：已辨識但未完整處理的敏感欄位醒目顯示風險，使用者明確確認後仍可複製。確認不預先選取，只對當次結果有效；修改或重新產生後失效。確認後提示仍可見，既有可逆性、JSON 與其他硬性阻擋不得越過。

具體要求與驗收條件見《ContextMask-介面調整規格補充》。
