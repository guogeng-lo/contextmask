# ContextMask

貼給AI除錯之前，先把程式碼、設定檔和錯誤訊息裡的隱私換成代號；AI回覆之後，再換回原本的內容。

```text
原文    File "C:\Users\wang\Desktop\hw5\main.py", line 42
遮罩後  File "C:\Users\USER_1\Desktop\hw5\main.py", line 42
```

路徑只換掉使用者名稱那一段，斜線、檔名和行號都留著，AI還是看得懂錯誤在哪裡。

**網頁版：[https://guogeng-lo.github.io/contextmask/](https://guogeng-lo.github.io/contextmask/)**

## 我做這個工具的出發點

> **把使用者當成什麼都不會的人來設計。**

這句有點嗆，但我是認真的。我不假設使用者會仔細看說明、會點開收起來的東西，連我自己當使用者都不一定會。所以會影響隱私的提示要放在不用點開就看得到的地方，工具找不到的東西要直接講，第一次用的人也要知道下一步該做什麼，正常的流程又不要多加步驟。

這句話是我操作v1.1時才講出來的，但從選題目到每一個設計決定（D01～D04），我一直都是用「使用者會不會看不懂、會不會漏看、會不會覺得麻煩」在判斷。需求是我提的、方案是我選的、使用體驗是我自己操作評估的、測試和查錯是我要求的。每個決定怎麼對回這個想法，寫在[規格書](docs/spec-v1.3.md)第二節。

## 怎麼用

打開網頁版：[https://guogeng-lo.github.io/contextmask/](https://guogeng-lo.github.io/contextmask/)，或下載`index.html`直接用瀏覽器打開（不用安裝，也可以離線用）。

1. 貼上錯誤訊息、程式碼或設定檔；姓名、學號這種規則猜不到的，可以加進自訂文字。
2. 按「掃描敏感資訊」，逐筆決定要遮罩還是保留。
3. 按「產生遮罩結果」，再按「複製給AI」，貼到AI的對話框問問題。
4. 把AI的回答貼回第4步。
5. 按「還原代號」，看摘要確認哪些代號換回來了、哪些沒換。

想先看看效果，可以按右上角的「載入範例」，範例裡的資料都是虛構的。

第一次用的話，頁面最上面有「第一次用？照這5步做」，每一步寫了該看哪裡、該按什麼。可以貼給AI的只有第3步複製出來的內容；第1步的原文和第5步的還原結果都有你的隱私，不要貼給AI。

頁面上方也寫了工具找得到什麼、找不到什麼；複製按鈕上方的「送出前再看一次」會列出送出前要注意的事，不用點開就看得到。

## 隱私

- 網頁在你的瀏覽器裡處理文字，不會把貼上的內容傳到伺服器，也不會存進瀏覽器的儲存空間；對照表只在這個分頁裡，重新整理或關掉就清除。
- 網頁用CSP禁止對外連線，但CSP管不到瀏覽器擴充功能、輸入法、剪貼簿工具這些網頁以外的程式，複製出去的內容也一樣。
- 規則只認得常見的格式，沒抓到不代表沒有敏感資訊。認出來但沒辦法完整遮住的地方，會在複製前列出來，要你確認才能複製。

## 誰做了什麼

這是我的課堂作業，用Vibe Coding的方式做。題目、需求規劃、使用體驗的設計和設計決定（D01～D04）是我做的，我也自己操作評估、提出測試和查錯的要求；程式、大量的自動測試和隨機測試、程式層面的查錯，由AI依照我的規格和要求完成。每一輪要改什麼、哪些AI的建議要採用，都是我決定的。過程記在規格書第十節和修改紀錄。
